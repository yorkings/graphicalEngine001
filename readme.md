## Graphical computing using SIMD and VUlkan
This will cover raytracing then build up towards a graphical engine


### Requirements
---
for  you who need just to test this app just do this

1. install cmake  and create  this directory 
 ```
 mkdir build
 ```
2. run this command
```
 cd build  &&
```

3. run this command 
```bash
 cmake --build build/.
 ```

then you see the generated file  run
``` bash
./GraphicsEngine 
```

4. ensure you have  installed vulkan libraries and headers if not see vulkan docs
